# Claude Code Arsenal Marketplace

A Cowork marketplace bundling 169 skills + 38 agents from Claude Code CLI.

## Install in Cowork

1. Cowork Settings -> Plugins -> Add marketplace
2. URL: https://github.com/KratosAR/claude.usage.advisor branch marketplace`n3. Install `claude-code-arsenal`

## Contents

- 169 skills (TDD, code review, security, planning, multi-language patterns, etc.)
- 38 agents (planner, architect, code-reviewer, security-reviewer, build-resolvers per language)
- Compatible with Cowork plugin format
